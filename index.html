Обо мне

На текущий момент, моей основной деятельностью является системное администрирование. Но параллеьлно с этим, в свободное время, занимаюсь веб разработкой, и планирую продолжать развитие в этом направлении. Первые шаги в веб, начались с трехмесечного курса на GeekBrains, где я получила базовые навыки верстки и js. Следующим опытом для меня, были курсы от компании ЦФТ - проект focus start, данный проект был ориентирован на начинающих frontend разработчиков. В рамках этого проекта я получила много полезных для себя практических навыков. На данный момент я имею знания в HTML и CSS, которые позволяют мне верстать определенный ряд макетов. Помимо чистого HTML, CSS в проектах использовала Bootstrap и MDL библиотеки, а для задач с клиентской логикой использовала JS а так же был опыт реализации проекта с использованием React. В просессе разработки пользуюсь VCS git и Atom IDE. На данный момент в моем портфолио есть несколько работ. Ознакомиться с ними и посмотреть демо вы можете в разделе проекты.
